# MQTT Battery Monitor

A project for monitoring battery telemetry over MQTT.

## Project Structure

- **`src/`** — Source code for the monitor (firmware, scripts, services).
- **`docs/`** — Documentation, specs, diagrams, and notes.
- **`assets/`** — Images, schematics, datasheets, and other non-code resources.
